# 我的任务地图

以后打开：在个人“应用程序”文件夹双击“我的任务地图”，或按 Command + 空格搜索这个名字。不需要打开终端或输入网址。

## 怎么用

1. 选中地图里相关的事，写下想法，点“帮我拆步骤”。
2. 等步骤出来后，检查内容，点“把这些步骤加进去”；不合适就点“先不用”。
3. 点具体步骤，补充要做什么、做好标准，选择模型并保存。
4. 点“让 Codex 做这步”，再用“看看进度”查看结果。
5. 检查结果，写下依据，选择“做得可以”或“需要修改”。

“打开对话”用于到 Codex 继续。已经由 Codex 桌面占用的旧对话，需要回到原对话执行。

## 保存在哪里

应用：`/Users/macmini/Applications/我的任务地图.app`

源码和运行文件：`/Users/macmini/Developer/threadmap-executable-design`

地图与记录：源码目录中的 `threadmap_state.json`，不上传 GitHub。保留该目录和已安装的 Codex；本应用目前依赖它们。

关闭窗口不会丢失已保存内容。退出应用时，应用自己启动的空闲服务会停止；有任务运行或状态尚未确认时会提示并保留服务。再次打开会复用已有服务，不重复启动。

AI 规划和执行需要网络与 Codex 登录；本地保存的地图不收费。次数限制用于防止误操作，不是账单金额；未收到实际模型或用量证据时显示“未知”，不冒充已核实。

## 键盘操作

Command + C / V / A：复制、粘贴、全选。
Command + W：关闭窗口。
Command + R：重新加载已保存的内容。
Command + Q：退出应用。

## 重新构建

在源码目录执行 `zsh macos/build.sh --replace-known`。构建脚本只替换相同应用标识的已知安装，旧版本保留在 `macos/build/`；该目录不上传源码仓库。

## 当前尚未通过的检查
